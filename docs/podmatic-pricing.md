# Podmatic 定价协议：型号池

> 本文是 v2 设计（[`podmatic-v2-design.md`](podmatic-v2-design.md)）的定价层。它取代了 v2 中“卖家挂价 + 预言机上限”的定价方式。
> 对照模拟见 [`sim/pricing_sim.py`](../sim/pricing_sim.py)，结果见 [`sim/pricing_results.md`](../sim/pricing_results.md)。

---

## 0. 一页结论

**问题**：v2 让卖家自己挂价，再用外部预言机限制挂价不超过参考价的 105%。这套办法有两个漏洞：

1. 卖家会把价格挂在上限附近；
2. 预言机滞后或有误差时，套利者会专门把被高估的卡挂进来，最后由玩家买单。

模拟结果（同一组市场条件，预言机有 7 天滞后和约 10% 的误差）：

| 指标 | v2：挂价 ＋ 预言机上限 | v3：型号池 |
|---|---|---|
| 玩家拿到的真实价值 ÷ 协议给的估值 | **约 92%**：展示返还率 89%，实际只有约 82% | **约 104%**：玩家实际拿到的比展示的略多 |
| 付给卖家的钱 ÷ 卡的真实价值 | **约 109%**：卖家拿到的溢价来自玩家 | **约 97%**：约等于外部市场扣费后的净价 |
| 估值偏差（中位 / P90） | 9% / 23% | 3.5% / 6% |
| 金库每交付 1 美元真实价值的净成本 | 约 1.08 美元 | 约 1.00 美元 |

**解法**：不让任何人报价。卡先按“型号”标准化，每个型号一个池子，价格由池子里的库存决定，外部套利把价格钉在市场价附近。卖家只给一个底价，表示“低于这个价我不卖”；成交价由池子决定，不由卖家决定。

> **Uniswap 让代币不需要订单簿就能交易，Podmatic 让收藏品不需要报价就能定价。**

还有一个更深的判断：NFT 自动做市（AMM）以前做不起来，是因为缺少不知情的买家，做市方总是被更懂行的交易者挑走好货。**抽卡就是 NFT 市场缺失的那批不知情买家。** Podmatic 把这两种流量分开：寄售卡只卖给抽卡的玩家，套利交易只和金库进行。

## 1. NFT 为什么难定价，Uniswap 给了什么启发

| 痛点 | 传统 NFT 市场 | Uniswap 在代币上的做法 | Podmatic 的做法 |
|---|---|---|---|
| 资产不标准 | 每个 NFT 都不一样，只能一张张估价 | ERC-20 让同一种代币完全可互换 | **型号标准化**：同一张卡、同一家评级机构、同一个分数视为可互换 |
| 价格靠人报 | 卖家报高、买家报低，靠挂单和报价单撮合 | 价格是池子库存的函数（x·y=k），没人报价 | **型号曲线**：每进一张降 2%，每出一张升 2% |
| 挂单要人维护 | 挂单过时、需要不停改价 | v3 的区间流动性：只设区间，被动成交 | **底价单**：只设最低可接受价，进入区间才可被抽中 |
| 价格依赖外部 | 依赖地板价、预言机，容易滞后和被操纵 | 套利者把池子价格推回外部价格 | **双向套利**：池子价格偏离市场时，套利者买入或卖出，直到价差消失 |
| 做市方被挑走好货 | 价格稍微过时，懂行的人就把被低估的货买走 | 噪音交易者付的手续费补偿 LP | **流量分离**：寄售卡只面对随机抽卡；金库面对套利者并收取价差 |
| 价格被操纵 | 刷单、拉地板价 | TWAP 预言机 | **TWAP 结算、估值取低，预言机只做熔断** |

## 2. 机制详解

### 2.1 型号标准化

**型号** = 卡牌（系列、编号、版本、语言）× 评级机构 × 分数。比如“1999 基础版喷火龙 4/102，PSA 10”是一个型号，所有这样的卡在经济上可以互换。

- 型号由托管适配器识别：适配器读出 NFT 对应的卡牌信息和评级证书，映射到型号编号。
- 同型号的卡进同一个池子。抽卡时先选型号，再从这个型号的池子里取一张。
- **不能标准化的卡不进型号池**：未评级卡、1/1 卡、有特殊瑕疵或签名的卡。这些卡只能走整卡众筹抽，用荷兰式降价拍卖定票价（第 2.9 节）。

评级卡的可互换性远好于 PFP 头像类 NFT：两张 PSA 10 的同款卡，在收藏市场上的价格几乎一样。这正是型号池能成立的前提。

### 2.2 型号曲线：价格是库存的函数

每个型号池有一个价格状态 P：

| 事件 | 价格变化 |
|---|---|
| 一张卡进入池子（金库买入、玩家卖回） | P ← P × (1 − δ) |
| 一张卡离开池子（被抽中、被直购） | P ← P × (1 + δ) |
| 池子里没有可抽的卡 | 每天 P ← P × (1 + 1%)，抬价吸引供给 |
| 可抽库存超过目标量 | 每天 P ← P × (1 − 0.5%)，降价消化库存 |

默认 δ = 2%。池子对外报两个价：

- **买入价**（池子向卖家买）= P × (1 − f)
- **卖出价**（池子向买家卖）= P × (1 + f)

默认 f = 2%，也就是买卖价差约 4%。这和 Uniswap 的指数型曲线是一回事：价格只取决于池子里有多少货，没有任何人在报价。

### 2.3 底价单：卖家只说“最低多少”，不说“卖多少”

持有人把卡挂进型号池时，只填一个**底价** F：

- P ≥ F 时，这张卡**在区间内**，可以被抽中；
- P < F 时，这张卡**在区间外**，不会被抽中，也不领库存收益。这和 Uniswap v3 区间外的流动性不赚手续费是一样的；
- 被抽中时，卖家拿到的是**过去 3 天的时间加权均价（TWAP）**，不是自己的底价；
- 同一型号内按挂单时间排队，先挂先卖。卖家能看到“你前面还有 N 张”。

**为什么这样就解决了“卖家挂价偏高”：**

成交价由池子决定，底价只决定“卖还是不卖”。所以卖家如实填写心理底价是最优策略：
- 填高了，只会错过本来愿意接受的成交；
- 填低了，可能以低于心理价位的价格卖出。

想卖得比市场贵的卖家，**不会伤害玩家，只是等不到成交**。在 v2 的挂价模式下，这部分溢价是由玩家承担的。

### 2.4 谁和谁交易

| 交易 | 价格 | 说明 |
|---|---|---|
| 持有人 → 寄售进池子 → 抽卡玩家 | TWAP | 默认方式；只面对随机抽卡 |
| 持有人 → 金库（即时卖） | 买入价 P(1−f) | 立刻拿钱 |
| 玩家抽中后 → 金库（卖回） | 买入价 P(1−f) | 取代 v2 固定的 88% 回购 |
| 玩家抽中后 → 换抽额度 | 买入价 ＋ 1% | 鼓励留在生态内 |
| 套利者 → 金库 | 买入价 | 池子价格偏高时，套利者从外部买卡卖给金库 |
| 金库 → 套利者或收藏者（直购） | 卖出价 P(1+f) | **只卖金库自有的库存**，不卖寄售卡 |

### 2.5 流量分离：寄售卡只卖给不知情的买家

做市方最怕的是**知情交易者**：价格稍微过时，懂行的人就会精准地买走被低估的货，或者卖进被高估的货。NFT 的自动做市一直做不起来，主要就是这个原因。做市方面对的几乎全是知情交易者，没有足够的噪音交易去补偿亏损。

Podmatic 恰好有大量的噪音交易：**抽卡的玩家不挑卡，他们付钱买的是随机性和娱乐**。协议把两种流量分开：

- **寄售卡只卖给抽卡**。持有人面对的全是随机买盘，不会被套利者挑走。
- **金库负责和套利者交易**。金库是专业的做市方，用买卖价差和抽卡的庄家优势补偿套利损失。

这是型号池能成立的关键：持有人得到公平价格，金库承担价格发现的成本并为此收费，玩家支付娱乐溢价。三方各得其所。

### 2.6 无套利区间：价格为什么会贴着市场价

设外部市场价为 M，套利者在外部买卖的摩擦成本为 c：

- 池子买入价 > M × (1 + c) 时，套利者从外部买卡卖给金库。每卖一张，P 降 2%，直到无利可图。
- 池子卖出价 < M × (1 − c) 时，套利者从金库直购后拿到外部卖。每买一张，P 升 2%，直到无利可图。

所以 P 被钉在：

```
M × (1 − c) / (1 + f)  ≤  P  ≤  M × (1 + c) / (1 − f)
```

f = 2%、c = 1.5% 时，约为 M 的 96.5% 到 103.6%。**不需要预言机来结算，价格由套利维持。**

套利要能发生，同一张 NFT 需要在外部有市场。Collector Crypt 的卡本身就能在 Magic Eden 交易（v1 第 2 页），套利可以在链上几秒内完成。只有实物、没有链上市场的型号，套利要经过托管和代币化，周期以天计，价格收敛会更慢。

### 2.7 估值与结算

| 用途 | 用什么价格 | 原因 |
|---|---|---|
| 返还率计算（玩家视角） | min(P, TWAP) × (1 − f)，也就是买入价取低 | 玩家随时能按这个价卖回，所以展示的返还率是可兑现的 |
| 寄售人结算 | TWAP | 单笔拉盘影响不到结算价 |
| 档位划分 | TWAP | 型号随价格变化自动换档 |
| 金库净值 | 买入价 | 保守计价，不会高估 |
| 外部预言机 | **只做熔断** | P 与预言机偏离超过 30% 并持续 3 天，或出现单日跳变，暂停该型号的抽取，等待人工核查 |

### 2.8 新型号的冷启动：从下往上发现价格

一个型号第一次进入协议时，没有交易历史：

1. 有外部报价时，初始 P = 外部报价的 80%；没有外部报价时，初始 P = 首批底价单中位数的 80%。
2. 池子里没有在区间内的卡，P 每天上调 1%，直到碰到第一个底价单。**价格从下往上走，最先成交的是最愿意卖的人，金库永远不会在价格发现阶段多付钱。**
3. **价格置信度**：30 天内成交少于 3 次的型号，估值再打 9 折，并且不能进入传说档。成交越多，置信度越高。

### 2.9 非标准卡：荷兰拍卖定票价

不能标准化的卡（1/1、签名卡、未评级卡）没有型号池，只能走整卡众筹抽。票价用荷兰式降价拍卖确定：

- 卖家设一个起始总价和一个底价；
- 总价从起始价每小时下降，票数随之减少；
- 第一张票被买下时，总价锁定，剩余的票按这个价格出售；
- 降到底价仍没人买，拍卖结束，卡退还。

价格由第一个愿意付钱的买家决定，卖家的起始价再高也没用。

### 2.10 防操纵

| 攻击 | 结果 |
|---|---|
| 从金库直购拉高价格，等抽卡按高价结算 | 结算用 3 天 TWAP；拉盘期间套利者会把卡卖回金库压价；每次直购都要付 2% 价差 |
| 刷单 | 自买自卖每个来回损失约 4% 价差，价格最终仍会被套利拉回 |
| 底价单挂高价“占位” | 区间外的卡不能被抽中、不领收益，对价格没有影响 |
| 伪造型号 | 型号由托管适配器从评级证书读出，不能自己声明 |
| 薄型号被操纵 | 置信度规则：成交太少的型号打折估值、不能进传说档 |
| 预言机被操纵 | 预言机不参与结算，只能触发暂停 |

## 3. 模拟对照

`sim/pricing_sim.py` 在同一组市场条件下比较两种机制：

- 一个档位（50 美元机的稀有档，75–200 美元），150 个型号，180 天，日均 80 抽；
- 每个型号的真实市价按日随机游走，偶有 ±20% 的跳变；
- 外部预言机等于 7 天前的市价乘以一个持续性误差（标准差约 10%）；
- 持有人陆续到达，心理底价中位数比市价高 5%；
- 套利者可以在外部按市价 ±1.5% 买卖同型号的卡；
- 玩家抽中后，只有卖回价不低于外部净价（市价的 97%）时才卖回。

结果（20 条路径的中位数，完整表见 `sim/pricing_results.md`）：

（初步结果：2 条路径。20 条路径的完整结果生成后会替换这张表。）

| 机制 | 真实价值 ÷ 估值 | 付给卖家 ÷ 真实价值 | 金库每交付 1 美元的净成本 | 估值偏差 中位 / P90 | 持有人成交数 | 底价 ≤ 市价的占比 | 等待天数中位：底价 ≤ 市价 / > 市价 | 套利卖入 / 买出 |
|---|---|---|---|---|---|---|---|---|
| v2 挂价＋预言机上限 | 92.3% | 109.4% | $1.077 | 9.1% / 23.3% | 4,259 | 53% | 5.5 / 5.0 | 5,657 / 0 |
| v3 型号池 | 104.0% | 96.8% | $0.995 | 3.5% / 6.3% | 4,379 | 59% | 15.0 / 34.5 | 1,618 / 3,298 |

**怎么读这张表：**

1. **v2 的问题是系统性的，不是运气**。预言机每次高估，套利者就从外部买卡、按上限挂进来；预言机低估时，持有人不挂，这些卡也就不会进入机器。机器里永远沉淀着被高估的卡，玩家的真实返还率比展示的低约 7 个百分点。
2. **型号池让三方的价格都回到市场价**。玩家拿到的真实价值不低于展示值，卖家拿到外部净价，金库每交付 1 美元价值大约花 1 美元。
3. **代价是：想卖高价的人卖得慢**。底价不高于市价的持有人，成交天数中位约两周；底价高于市价的持有人，大部分等不到成交。v2 里他们“成交快”，是因为玩家在替他们付溢价。这是一个必须向持有人讲清楚的取舍：想快，就选即时卖给金库（约为市价的 96%）；想多拿，就把底价设在市价附近排队。

## 4. 对 v2 的修订

| 项 | v2 | v3 型号池 |
|---|---|---|
| 卖家给什么 | 挂价（≤ 参考价 105%） | 底价单 |
| 成交价 | 卖家的挂价 | 型号池的 TWAP |
| 档位依据 | 外部参考价 | 型号池 TWAP |
| 档内选卡 | 按 (V/a)^3 加权 | 先按在区间内的张数选型号，型号内先挂先卖 |
| 外部预言机 | 决定挂价上限和返还率 | 只做熔断 |
| 玩家现金卖回 | 固定 88% | 型号池买入价，约为价格的 96% |
| 以卡换抽 | 95% | 买入价 ＋ 1% |
| 即时卖给金库 | 参考价 90% | 型号池买入价 |
| 库存收益 | 在架寄售卡都领 | 只有**在区间内**的寄售卡领 |
| 玩家立即卖回的每抽真实成本 | 约 21% | 约 15% |
| 金库 LP 收益占流水 | 约 8% | 约 5%（回收价差变小），见 `sim/results.md` 的“v3 市价卖回”场景 |

LP 收益下降是有意为之：原来 12% 的回购价差本质上是向玩家收的隐性费用，现在还给了玩家。LP 仍然有庄家优势和买卖价差两项收入，模拟中仍然盈利。

## 5. 叙事

v2 的叙事是“收藏品的做市协议”。有了型号池，这个叙事变得具体：

- **对行业**：NFT 流动性差，根子在定价：每张卡都要人来估价、报价、撮合。Podmatic 把卡变成标准型号，让价格从库存里长出来，再用套利钉住市场。这正是 Uniswap 对代币做的事。
- **对持有人**：你不用会定价。告诉协议你最低能接受多少，剩下的交给市场。成交价永远是市场价，不会更低。
- **对玩家**：返还率按“你随时能卖回的价格”计算，展示多少就是多少。
- **对做市方**：这是第一个有足够噪音交易的 NFT 做市场所。抽卡流量为做市付费，持有人不会被套利者挑走好货。

一句话：

> **抽卡是 NFT 市场缺失的噪音交易者，型号池是 NFT 市场缺失的定价曲线。两者合在一起，非标准资产第一次可以像代币一样被定价。**

## 6. 链上实现

**账户**

| 账户 | 内容 |
|---|---|
| SkuPool | 型号编号、当前价格 P、TWAP 累加器、上次漂移时间、金库自有库存数、价格置信度 |
| PriceTick | 按 2% 分档的价格刻度，每个刻度记录挂在这个底价上的寄售张数（和 Uniswap v3 的 tick 同一个思路） |
| FloorOrder | 一张寄售卡：NFT、底价刻度、挂单时间、所有人、收益记账 |
| PriceGuard | 外部预言机快照、熔断状态 |

**为什么用刻度**：底价单按 2% 的刻度归档，正好等于价格每次移动的步长 δ。在区间内的张数等于“刻度 ≤ 当前价格刻度”的张数之和，用树状数组可以在对数时间内维护。价格每跨过一个刻度，就有一批卡进入或离开区间，和 Uniswap v3 的流动性进出完全同构。

**指令**

- `place_floor`、`cancel_floor`：挂底价单、撤单（有未完成的抽取时不能撤）。
- `sell_to_pool`：按买入价卖给金库（持有人即时卖、玩家卖回、套利者卖入）。
- `buy_from_pool`：按卖出价直购金库自有库存。
- `poke_drift`：任何人都可以调用，按时间推进价格漂移和 TWAP。
- `fulfill_spin` 的选卡逻辑改为：在档位内按“在区间内的张数”选型号，型号内取最早的寄售卡或金库自有卡，按 TWAP 结算。

## 7. 开放问题

1. **型号粒度**：BGS 9.5 和 BGS 10 要不要分开？子分数、评级人口数要不要进入型号定义？分得越细越准，但每个池子越薄。
2. **每个型号的 δ 和 f 要不要不同**：高价、低流动性的型号可能需要更大的价差。
3. **套利者是否存在**：需要确认第一批型号在 Magic Eden 等外部市场有足够的成交。没有外部市场的型号，价格只能靠抽卡和持有人底价慢慢发现。
4. **初始价格的来源**：没有外部报价的型号，首批底价单中位数的 80% 是否足够保守？
5. **金库直购是否对普通收藏者开放**：开放会带来更多成交，但也让 Podmatic 变成一个普通交易所，可能影响监管定性。
